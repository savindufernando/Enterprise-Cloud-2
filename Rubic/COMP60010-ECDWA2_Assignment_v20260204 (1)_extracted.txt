Case Study
Scenario: AeroLink Airline Systems Platform
You are part of an advanced software architecture team at AeroLink, a global airline systems and aviation technology provider supporting airlines and airport operators across multiple regions.
AeroLink delivers critical digital services such as flight booking and ticketing, passenger checkin, baggage tracking, flight operations management, and integration with thirdparty systems including airports, immigration authorities, and payment providers.
AeroLink currently operates on a monolithic architecture, which is increasingly unable to support the organisation’s requirements for:
High availability
Global scalability
Fault tolerance
Realtime data synchronisation
To address these challenges, AeroLink is transitioning to a cloudnative, microservicesbased architecture that integrates cloud services and distributed applications through secure and scalable APIs.
Your task is to design and implement a cloudbased distributed web application that meets AeroLink’s operational, scalability, and regulatory requirements.

Assignment Tasks
1. CloudBased Web Application Design
Design a comprehensive cloudbased architecture for AeroLink using appropriate cloud services. Your design should consider:
Microservices architecture
Containerisation (e.g., Docker, Kubernetes)
Serverless computing (e.g., AWS Lambda)
Cloudmanaged databases (e.g., Amazon Aurora, DynamoDB)
The design must clearly address:
High availability
Multiregion deployment
Horizontal scalability
Architectural diagrams and explanations are required.

2. Distributed Web Application and API Design
Design and implement a distributed system composed of loosely coupled microservices that communicate using:
RESTful APIs and/or
Eventdriven architecture (e.g., Kafka, AWS EventBridge)
Your solution must include:
An API Gateway for routing and authentication
API documentation (Swagger / OpenAPI)
Secure servicetoservice communication

3. Data Security, Compliance, and Consistency
Design a security model to protect sensitive customer data by addressing:
Encryption at rest and in transit
Authentication and authorisation (OAuth 2.0, JWT, RBAC)
Compliance with regulations such as GDPR and PCIDSS
Discuss data consistency challenges in distributed systems and justify your chosen approach (e.g., eventual consistency, Saga pattern, CQRS).

4. RealTime Data Synchronisation
Implement realtime data synchronisation mechanisms to ensure that:
Flight seat availability updates
Baggage status changes
Flight schedule and pricing updates
are reflected across services with minimal delay. Use eventdriven cloud services where appropriate.

5. Fault Tolerance and Resilience
Demonstrate how your system achieves fault tolerance through:
Retry policies and circuit breakers
Autoscaling and load balancing
Highavailability zones and disaster recovery strategies

6. Performance and Scalability Testing
Conduct performance testing, including:
Load testing
Stress testing
Analyse latency, throughput, and error rates, and discuss potential performance improvements.

7. Monitoring and Observability
Implement monitoring and observability using cloudnative tools such as:
AWS CloudWatch 
Include logging, metrics, and distributed tracing to demonstrate system health and fault diagnosis.

8. Testing Strategy
Unit testing of individual microservices
Integration testing of APIs and cloud services
API testing using tools such as Postman or Swagger
Provide evidence and discussion of test results.
